## Physical level

**Физический уровень** — отвечает не за передачу данных, а за передачу электрических сигналов, световых или радиосигналов.
Его главная задача преобразовать последовательность битов `01010101…` в _электрические импульсы_, _световые импульсы_, _радиоволны_ и обратно.

> На физическом уровне нет понятия "пакет", есть только _поток бит_, например: `110010101010100101010`, то есть физический уровень не понимает,
> где начало сообщения. Для него это просто изменение напряжения или света.

### Среды передачи


| Среда         | Что изменяется                   |
| ------------- | -------------------------------- |
| Медный кабель | Электрическое напряжение или ток |
| Оптоволокно   | Интенсивность света              |
| Wi-Fi         | Электромагнитные (радио) волны   |

Cуществует всего три основные способа передачи информации.

#### 1. Электричество

Используется:
- Ethernet по витой паре (хорош для локальных сетей)
- старые телефонные линии

Передача происходит *изменением напряжения*. 

Например:

```
+1 B = 1
0 B = 0
```

или немного сложнее (так как могут появлятся помехи и необходимо использовать более сложные методы кодирование сигнала из-за помех, что могут возникать). 

#### 2. Свет 

Используется:
- оптоволокно (лучший на длинных расстояниях)

Передается _лазер_, который либо включается (`Свет есть -> 1`), либо `Нет света -> 0`. (Но это простой пример, используются более сложные методы кодирования)

#### 3. Радиоволны

Используются:
- WiFi
- Bluetooth
- 4G, 5G
- спутники

Информация кодируется изменением _частоты_, _фазы_ и _амплитуды_.

### Что такое Сигнал

**Сигнал** — это изменение физической величины во времени, используемое для передачи информации.

> Если физическая величина не меняется, то значит информация не передается. И наоборот.

#### Аналоговый сигнал

Аналоговый сигнал может принимать **любое значение** в некотором диапазоне.

Например, напряжение может быть:

```
0.1 B
0.25 B
2.67 B
4.99 B
```

То есть количество возможных значений практически _бесконечно_.

Пример графика:

```
Напряжение

5V |          /\
   |         /  \
3V |        /    \__
   |      /
1V |_____/________________► время
```

Так работают:

- микрофон.
- человеский голос.
- старое аналоговое радио.
- виниловые пластинки.

> **Плюсы аналогового сигнала:** Простота генерации и естественно описывает физический мир, например: _звук_, _температура_, _давление_, _освещенние_, так как все эти величины изменяются плавно.

> **Минусы аналогового сигнала:** Очень чувствитеоен к помехам. Например, если по дороге добавился _шум_.

#### Цифровой сигнал

Цифровой сигнал использует **ограниченное количество состояний** (`0`, `1`, то есть информация передается битами).

График выглядит примерно так:

```
5V ──┐      ┌──────┐
     │      │      │
0V   └──────┘      └────► время

     1 0 1 1 0
```

В реальном Ethernet кодирование сложнее, но идея остается такой же: данные представленны последовательностью битов.

<details>

<summary><b>Почему цифровой сигнал лучше переносит помехи?</b></summary>

Так как если придется сигнал например: 4.5 B, то приемник понимает это так, что оно близко к 5 значит -> `1`, или например сигнал пришел как 0.2 B, то приемник/получатель интерпретирует этот сигнал как `0`.

То есть небольшие помехи не меняют значение бита.

</details>

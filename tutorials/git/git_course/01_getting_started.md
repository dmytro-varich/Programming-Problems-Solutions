# 01. Getting Started

Первичная подготовка Git и проверка установки.

## Проверка версии Git

```bash
git --version
```

Выводит установленную версию Git.


## Справка Git

### Общая справка

```bash
git --help
```

###  Справка по команде

```bash
git <command> --help
```

или 

```bash
git help <command>
```

# 01. Getting Started

Первичная подготовка Git и проверка установки.

## 1. Проверка установки

```bash
git --version
```

Выводит установленную версию Git.

## Справка Git

### Общая справка

```bash
git --help
```

### Справка по команде

```bash
git <command> --help
```

или 

```bash
git help <command>
```

## Примечания

- Скачать [Git](https://git-scm.com/install/) из оффициального сайта.

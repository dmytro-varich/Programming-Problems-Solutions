# Git Cheat Sheet

## 1. Настройка и конфигурация

| Команда | Описание |
|----------|----------|
| `git config --global user.name "Имя"` | Установить имя пользователя |
| `git config --global user.email "email"` | Установить email пользователя |
| `git config --list` | Показать все настройки Git |
| `git config --global core.editor "editor"` | Установить редактор по умолчанию |

---

## 2. Создание и клонирование репозиториев

| Команда | Описание |
|----------|----------|
| `git init` | Создать новый локальный репозиторий |
| `git clone <url>` | Склонировать удаленный репозиторий |
| `git remote add origin <url>` | Добавить удаленный репозиторий |
| `git remote -v` | Показать список удаленных репозиториев |

---

## 3. Основной Workflow

### Работа с изменениями

| Команда | Описание |
|----------|----------|
| `git status` | Показать состояние рабочей директории |
| `git add <file>` | Добавить файл в индекс (Staging Area) |
| `git add .` | Добавить все изменения в индекс |
| `git commit -m "Сообщение"` | Создать новый коммит |
| `git commit --amend` | Изменить последний коммит |

### Просмотр истории

| Команда | Описание |
|----------|----------|
| `git log` | Показать историю коммитов |
| `git log --oneline` | Краткая история коммитов |
| `git log --graph` | История с визуализацией веток |
| `git show <commit>` | Показать информацию и изменения указанного коммита |

---

## 4. Ветки (Branches)

### Создание и переключение

| Команда | Описание |
|----------|----------|
| `git branch` | Показать список локальных веток |
| `git branch <name>` | Создать новую ветку |
| `git checkout <branch>` | Переключиться на существующую ветку |
| `git checkout -b <branch>` | Создать новую ветку и сразу переключиться на неё |
| `git switch <branch>` | Переключиться на существующую ветку (современный вариант) |
| `git switch -c <branch>` | Создать новую ветку и переключиться (современный вариант) |

### Слияние и удаление

| Команда | Описание |
|----------|----------|
| `git merge <branch>` | Слить указанную ветку в текущую |
| `git merge --abort` | Отменить процесс слияния |
| `git branch -d <branch>` | Удалить ветку (если она уже слита) |
| `git branch -D <branch>` | Принудительно удалить ветку |

---

## 5. Работа с удаленными репозиториями

| Команда | Описание |
|----------|----------|
| `git fetch` | Загрузить изменения с удаленного репозитория без слияния |
| `git pull` | Загрузить и сразу слить изменения |
| `git push` | Отправить изменения в удаленный репозиторий |
| `git push -u origin <branch>` | Отправить ветку и установить отслеживание (upstream) |
| `git push --force` | Принудительно отправить изменения (**использовать с осторожностью**) |

---

## 6. Отмена изменений

| Команда | Описание |
|----------|----------|
| `git restore <file>` | Отменить незакоммиченные изменения в файле |
| `git restore --staged <file>` | Убрать файл из индекса (Staging Area) |
| `git reset --soft <commit>` | Вернуться к указанному коммиту, сохранив изменения в индексе |
| `git reset --hard <commit>` | Полностью вернуться к указанному коммиту, удалив все изменения |
| `git revert <commit>` | Создать новый коммит, отменяющий изменения указанного коммита |

---

## 7. Временное сохранение изменений (Stash)

| Команда | Описание |
|----------|----------|
| `git stash` | Временно сохранить текущие изменения |
| `git stash list` | Показать список сохраненных изменений |
| `git stash pop` | Восстановить последние сохраненные изменения и удалить их из списка |
| `git stash apply` | Применить сохраненные изменения без удаления из списка |
| `git stash drop` | Удалить сохраненные изменения |

---

## 8. Инспекция и сравнение

| Команда | Описание |
|----------|----------|
| `git diff` | Показать незакоммиченные изменения |
| `git diff --staged` | Показать изменения, добавленные в индекс |
| `git diff <commit1> <commit2>` | Сравнить два коммита |
| `git blame <file>` | Показать автора каждой строки файла |
| `git grep "текст"` | Найти текст во всех файлах репозитория |
